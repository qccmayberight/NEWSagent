# config/ —— 配置文件夹

这里存放整个 Agent 的“设置”，修改这里就能改变程序的行为，不需要动核心代码。

## 文件说明

### `sources.py`（核心配置，最常改动的文件）

**作用**：定义新闻从哪里来、每个分类给 AI 分析多少条。

- `RSS_SOURCES`：RSS 订阅源列表。每一项是一个字典：
  - `name`：来源名称（会显示在日报里）
  - `url`：RSS 订阅地址
  - `category`：分类，只能是 `"ai"`、`"ai_coding"` 或 `"economy"`，决定它出现在日报的哪个板块、以及被算进哪类分析
  - `language`：语言标记（`zh` / `en`），方便阅读时区分
- `MAX_ITEMS_PER_CATEGORY`：每个分类最多送多少条新闻给 Kimi 分析（防止内容过长超出模型限制）。
- `MAX_SUMMARY_CHARS`：每条新闻摘要最多保留多少字符。

**怎么加新闻源**：照抄列表中任意一项，改成新的名称和 RSS 地址即可。大部分新闻网站的 RSS 地址可以在网上搜“网站名 + RSS”找到。

### `__init__.py`

**作用**：Python 的包标记文件。内容为空，它的存在让 `config` 文件夹可以被其他代码当作“模块包”导入（例如 `from config.sources import RSS_SOURCES`）。不要删除。

## 相关配置文件（在项目根目录，不在本文件夹）

- `.env`：存放 API 密钥等私密配置，由 `.env.example` 复制而来，**不要分享给别人**。
- `.env.example`：模板，告诉使用者需要配置哪些环境变量。
