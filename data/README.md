# data/ —— 运行数据文件夹

这里存放程序**运行时自动产生**的数据，不需要手动编辑，也不建议分享（对你的朋友没有用处，他们运行时会自动生成自己的）。

## 文件说明

### `seen.json` —— 已读新闻记录（自动生成）

**作用**：记录所有已经上过日报的新闻链接，供 `core/store.py` 去重使用。

- 每运行一次日报任务，新出现的新闻链接会被追加进来。
- 最多保留最近 5000 条，超出后自动丢弃最旧的记录。
- **删掉它**相当于“清空已读”，下一次运行会把时间窗口内的新闻全部当作新内容再报道一次，不会造成其他影响。

> 提示：如果把项目分享或提交到 Git，建议不要包含本文件（可在 `.gitignore` 中加入 `data/seen.json`）。
