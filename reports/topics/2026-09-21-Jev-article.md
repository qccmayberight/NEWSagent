# 公众号文章 · Jev · 2026-09-21

# 输出不要钱、速度快200倍：OpenAI元老做的「Jev」，为啥刷屏了？

这两天，一个叫 Jev 的 AI 模型突然全网爆火，褒贬不一，但很多人都嗅到了一种"开宗立派"的味道——因为它根本不是来做大模型竞争的，它甚至不生成文字。

故事的开端很有戏剧性：9 月 15 日，前 OpenAI 核心研究科学家 Diogo Almeida 在社交平台发帖，抛出一个灵魂拷问——**为什么 ChatGPT 发布之后，聊天模型的 AGI 依然迟迟没有到来？** 他给出的答案是：因为他们过去几年一直在秘密训练一种新型模型，叫 Jev。这条帖子迅速冲到 3600 万浏览，Jev 就此出圈。

这位 Diogo 来头不小——他是 RLHF（人类反馈强化学习）和 InstructGPT 的核心发明人之一，当年正是他参与奠定了 ChatGPT 的整套对齐范式。这样一位亲手缔造了对话大模型地基的大佬，如今亲自出来"推翻自己"，这事本身就足够引爆科技圈。

## 一、Jev 到底是什么？一句话：它不说人话

传统大模型的玩法是"输入文本、生成文本"，而 Jev 把这个环节整个砍掉了。

TypeSafe AI（总部在旧金山，Diogo 正是其创始人）给 Jev 的定位是：**专门用于机器结构化决策的底层引擎（Programmatic Decision Engine）**。它不用来聊天、不写文章、不写诗，只做一件事——判断。

这里可以借用丹尼尔·卡尼曼在《思考，快与慢》里的经典框架来理解：

- **传统大模型是 System 2（慢思考）**：像人类深思熟虑那样逐词推演，能力强，但慢、贵、啰嗦；
- **Jev 是首个 System 1（快思考）大模型**：模拟人类大脑那种毫秒级、直觉式的本能反应。

有趣的是，System 1 + System 2 恰好对应人脑中的"情绪脑+理智脑"结构。也就是说，Jev 没想取代 ChatGPT，它更像是给大模型装上了"脊椎反射"——大部分日常判断根本不必动脑子想半天。

## 二、原理拆解：三步看懂 Jev

### 1. 抛弃自回归，单次前向传递

传统大模型慢，是因为它必须一个 token 一个 token 往外"吐"——哪怕你只是问一句"这段话是不是垃圾邮件"，它也得完整走一遍解码流程。

Jev 则是**非自回归**架构：开发者只需传入一段未结构化的状态数据（一封工单、一段日志、一帧游戏画面）+ 一组预定义好的带类型问题，Jev 通过**单次并行前向传递（Single Parallel Pass）**，在几毫秒到几十毫秒内一次性返回所有维度的决策结果。

### 2. 三种强类型决策原语

Jev 抛弃了容易出歧义的"Prompt 玄学"，只支持三种标准化输出：

- **Noul**（伯努利二元判断）：回答 Yes/No 问题，名字来自 No + Boolean 的合成，直接返回 0.0~1.0 的精确概率值，而不是一个简单的 true/false；
- **Choice**（有限选项分类）：从最多 255 个预定义选项中选出最匹配的，并给出全概率分布和置信度；
- **Score**（多阶梯度评分）：按预设标准（如 0~10 级）返回带置信度的连续数值，衡量严重性、紧迫度或相关性。

### 3. 用 RLCD 取代 RLHF，专治"过度自信"

这是 Diogo 真正想颠覆的东西。他太清楚 RLHF 的工程软肋了：RLHF 的目标是**迎合人类喜好**，导致模型常常为了讨好用户而过度自信、产生幻觉。

而 RLCD 的优化目标是**认识论上的概率校准（Epistemic Calibration）**——意思是：当 Jev 说"我有 90% 把握"时，它在统计上的真实准确率就恰好是 90% 左右。这种"诚实"让开发者可以安心设置自动化阈值，比如：

```python
# 置信度高于 0.88 自动执行，否则转人工
if decision.confidence > 0.88:
    execute_automation()
else:
    route_to_human_agent()
```

## 三、为什么突然火了？便宜、快、有光环、Demo 炸

**第一，便宜到离谱。** 按官方定价：输入 Token 每百万仅 0.042 美元（十亿 Token 只要 42 美元），**输出完全免费**——官方的说法是"输出成本低到无需计量"。对比一下：当红旗舰模型（如 GPT-6 Astra、Claude Fable 5.1）输入约 10 美元/百万 Token、输出高达 50 美元/百万 Token。仅看输入，Jev 便宜 238 倍；算上免费输出，在真实的分类、路由、微决策场景中，**综合成本低 500 到 1000 倍**（此为厂商口径及社区测算，不同场景会有出入）。顺带一提，"Jev"这个名字正是致敬经济学上的**杰文斯悖论**——技术让资源使用效率暴增，总消耗反而指数级爆发。

**第二，延迟降维。** 官方口径显示，Jev 端到端延迟通常在 70~500 毫秒之间，轻量场景甚至能压到十几毫秒，相比通用大模型动辄数千毫秒的调用链，**提速接近 200 倍**。做过后端的人都知道这意味着什么：以前很多场景不是不想用大模型，是不敢用——一旦卡死整个链路就崩了。

**第三，创始人光环 + 生态配合。** Vercel CEO Guillermo Rauch 亲自站台，Jev 发布首日即通过 Vercel AI Gateway 和 AI SDK 获得原生支持；官方同步上线 Python 和 Node/TypeScript SDK，并接入 OpenRouter；TechCrunch、Forbes 等媒体密集报道。据 Vercel 官方统计，Jev 是其 AI Gateway 历史上采用速度最快的模型。

**第四，Demo 太有冲击力。** 两个流传最广的演示：一是 **Minecraft 实时生存 Agent**——以往 LLM 控制游戏角色有 1~3 秒延迟，僵尸贴脸了还在"思考"；Jev 每隔几十毫秒并行输出动作决策与风险评分，实现实时走位、躲避、找庇护所，全程零硬编码规则。二是**《地铁跑酷》毫秒级避障**——高频反应类游戏曾是大模型禁区，Jev 针对每一帧画面输出 [Jump, Duck, MoveLeft, MoveRight] 的置信概率，行云流水。社区几天内还自发上线了生态导航站 Jevable.com。TypeSafe AI 给这套理念起了个口号：**Prod, Not God（交付生产，而非盲目造神）**——直戳这两年"卷参数、卷算力、追 AGI"的行业疲劳。

目前 Jev 通过官网白名单申请开放使用，申请基本次日即可通过，新用户有 5 美元额度——由于输出免费，这 5 美元实际能用很久。

## 四、真实能力与局限：冷静一下

火归火，得泼点冷水。基于公开信息，Jev 的局限其实和它的优势一体两面：

- **它只能做"预定义问题"的判断**。Choice 最多 255 个选项，Noul 只有是/否，Score 只有打分——开放性、创造性的任务与它无关。它需要的一切问题都得事先结构化定义好。
- **它依赖 RLCD 校准的真实表现，目前主要是厂商宣称**。校准率是否在所有领域都稳定达标，需要更多第三方在真实业务数据上验证——毕竟 RLHF 的过度自信问题，换个训练方法未必药到病除。
- **输出免费是商业策略，也可能伴随限流、配额**。官方说输出"too cheap to meter"，但一旦规模化调用，实际体验如何、免费策略持续多久，都有待观察。
- **复杂任务仍需 System 2 兜底**。长链推理、开放创作、复杂代码架构，Jev 都不做。它不是 AGI 的替代品，只是流水线上的一个"神经反射"组件。

## 五、争议点：是真革命，还是又一次营销？

围绕 Jev 的争论主要集中在三处：

1. **"首个 System 1 大模型"的成色。** 非自回归、分类头输出、轻量模型做路由——这些单项技术在工业界并非全新，Jev 的贡献更多是把这些能力以"校准概率 + 工程化产品"的形式整合打包。批评者认为其中不乏概念包装；支持者则认为，把被行业忽视的赛道彻底打通，本身就是贡献。
2. **创始人自我颠覆的可信度。** Diogo 一边靠 RLHF 功成名就，一边宣称 RLHF 有致命工程缺陷——这被解读为深刻的反思，也被质疑是"为自家新故事站台"。但无论如何，"RLHF 迎合人类喜好导致过度自信"这个批评，确实切中了很多从业者的真实痛感。
3. **Demo 的含金量。** Minecraft 和跑酷 Demo 极具视觉冲击力，但 Demo 场景高度可控，离金融风控、医疗分诊这类"决策错了代价巨大"的生产场景还有距离。校准宣称在这些高风险领域能否兑现，才是真正的试金石。

## 六、未来怎么走？

综合各方信息，趋势已经比较清晰：

**第一，System 1 + System 2 的分工协作将成为主流架构。** 未来的 AI 应用大概率是：Jev 这类模型在边缘做毫秒级的意图路由、安全拦截、工单分流、状态判定，消化 90% 的低成本微决策；旗舰生成模型只在需要深度推理和创作时被唤起。这不是谁淘汰谁的问题，而是各就其位。

**第二，开源复刻潮已经来了。** Bespoke Labs 已火速开源 Bespoke Nimble——基于 Qwen3.5-9B 底座，完整开放数据、权重和训练配方，打响了开源复刻的第一枪。既然技术路径已清晰，接下来几个月 Hugging Face、vLLM 等生态大概率会跟进一批轻量开源决策模型，私有化部署成本还会进一步下探。这对 TypeSafe AI 既是威胁，也是赛道被验证的证明。

**第三，AI 开发将从"Prompt 玄学"回归软件工程。** 过去几年开发者最痛苦的事，莫过于哄大模型老老实实输出合法 JSON。强类型决策原语 + 可校准置信度，意味着工程师可以用传统的方式写确定性业务逻辑，而不是和概率"斗智斗勇"。这可能就是 vibe coding 真正走向"Happy Ending"的路径之一。

## 我的判断与观察点

我的看法是：Jev 短期爆火里确实有营销和创始人光环的加持，但**它踩中的方向是真的**——大模型行业正在从"造一个全能之神"转向"把智能拆成便宜、可靠、可嵌入流水线的零件"。价格降百倍、延迟降百倍、输出带诚实置信度，这三件事叠加，足以打开大量以前"用不起、不敢用"的场景。即便 Jev 本身不成，这个范式也会被别人做成。

建议读者持续关注几个观察点：

1. **校准率的第三方验证**：有没有独立团队在真实业务数据上复现"说 90% 就准 90%"？
2. **免费输出的可持续性**：规模化之后会不会调整定价？
3. **开源社区的跟进速度**：Bespoke Nimble 之后，会不会出现性能更强、甚至超越闭源版的复刻？
4. **高危行业的落地案例**：金融风控、医疗分诊等场景敢不敢接、接得稳不稳，才是 System 1 的真正成人礼。
5. **System 2 厂商的反应**：OpenAI、Anthropic 会不会把类似的"快思考"能力内置进自家模型，让独立决策层失去存在空间？

Jev 或许不是终点，但它很可能是一个转折点：AI 的竞争，正在从"谁更聪明"转向"谁更便宜、更快、更诚实"。值得盯紧。
